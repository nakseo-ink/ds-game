# 컴퓨터를 모르는 백수, 부잣집 과외교사가 되다 — 자료구조 편

과외 서사 기반 인터랙티브 자료구조 학습 게임 (v0.32 · 2026-2학기).

컴퓨터를 모르는 백수가 부잣집 과외교사로 취직해, 학생 도윤이를 가르치기 위해
스스로 자료구조를 공부한다 — **플레이어의 공부가 곧 게임이다.**

**▶ 플레이: https://nakseo-ink.github.io/ds-game/** (PC·모바일 브라우저, 설치 불필요)

## 학생 안내

- **진도**: 15주 학기 구성 — 1주차 오리엔테이션부터 기말고사까지, 수업 진도와 같은 순서다.
  어느 주차든 자유롭게 시작할 수 있다.
- **완성학습**: 유닛마다 힌트 없이 연속 3회 정답까지 반복한다. 문항은 생성기가 무한히 변형하므로
  답을 외우는 것은 불가능하고, 이해만이 통한다.
- **서가(왼쪽 아래)**: 📕 자료구조 책(요점 정리 + 연습문제 28문·해답), 📘 쪽집게 C(C 문법 사전),
  🔖 책갈피(막힌 문제의 여백 메모·단서 수첩). 오답이 나오면 게임이 관련 절을 알려준다.
- **📒 과외 장부**: 상단 「도윤 성적」을 누르면 나의 학습 기록(주차별 정답률·다시 볼 곳·책 활용·학습 리듬)을
  언제든 확인할 수 있다. 이 기록은 내 기기에서만 계산되며 다른 사람과 비교되지 않는다.
- **저장·이어하기**: 씬 단위 자동 저장. 타이틀의 「진도 코드」로 다른 컴퓨터·폰에 진행을 옮길 수 있다.
- **과외비·상점**: 성적이 좋을수록 과외비가 오르고, 상점에서 쓸 수 있다. A+ 트랙과 시험에는 보너스가 있다.

## 학습 데이터 수집 고지

이 콘텐츠는 수업 개선과 교육 연구를 위해 학습 활동 기록(문항 응답, 진행 상황, 학습 시간대 등)을
**학번 단위로** 수집합니다. 첫 실행 시 학번을 입력하게 되며, 수집된 자료는 수업 운영과
교육 연구 목적으로만 사용되고 연구 발표 시에는 개인을 식별할 수 없는 형태로만 활용됩니다.
콘텐츠 사용은 자유이며 성적에 직접 반영되지 않습니다. 문의: 담당 교수.

## 구조 — 엔진 고정 + 챕터 = 데이터

빌드·서버 없는 정적 웹. `index.html` 더블클릭으로도 실행된다(로컬 실행 시 데이터 수집 없음).

```
index.html            셸 (HUD + 스크립트 로드)
css/style.css         스타일 (다크 테마 · 모바일 반응형 · 책 드로어 · 과외 장부)
img/                  키 비주얼 (타이틀 배경)
js/config.js          ★ 배포 설정 (Supabase 수집 키) — 배포자가 유일하게 수정하는 파일
js/logger.js          로그 큐 + 배치 전송 (오프라인 안전 · file://에서는 비활성)
js/util.js            공용 유틸
js/avatars.js         캐릭터 SVG
js/generators.js      문항 생성기 50여 계열 (파라미터 무작위 + 자체 재검산)
js/engine.js          씬 러너 + 위젯(스텝 실행·배열/트리/그래프 시각화·Parsons·문답)
                      + 시험 엔진 + 책 리더 공장 + 과외 장부 + 저장·상점
data/ch00~ch13        주차별 챕터 (대사·자습 비트·문항·서사 — 전부 데이터)
data/chM · chF        중간·기말고사 (문제은행 추첨)
data/exam.data.js     시험 문제은행
data/bookDS · bookC   📕 자료구조 책(14절) · 📘 쪽집게 C(25항목)
data/shop.data.js     상점 아이템
```

챕터 추가 = `data/chXX.data.js` 작성. 학기 중 기능 프리즈 — `js/`는 수정하지 않고 `data/`만 손댄다.

## 배포·수집 설정 (교수자용)

- GitHub Pages: `docs/GitHubPages-배포가이드.md`
- 학습 로그 수집(Supabase): `docs/Supabase-설정가이드.md` → `js/config.js`에 키 입력.
  키가 있으면 라이브(https)에서 학번 게이트와 수집이 자동으로 켜진다.
  `file://` 로컬 실행은 항상 수집·게이트 비활성(개발 모드)이다.
